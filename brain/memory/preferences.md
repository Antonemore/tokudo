# Working Preferences & Habits

- **Phong cách giao tiếp:** Ngắn gọn, chính xác, trực diện, không rườm rà. Luôn ưu tiên đưa ra giải pháp kèm code hoặc lệnh cụ thể.
- **Quy chuẩn mã nguồn:**
  - Viết code sạch (Clean Code), có type hints rõ ràng.
  - Xử lý bất đồng bộ (async/await) đúng chuẩn, không gây block Event Loop.
  - Luôn kiểm tra ngoại lệ và bảo vệ tài nguyên hệ thống.
- **Quy chuẩn điều khiển hệ thống:**
  - Lệnh can thiệp sâu hệ thống Windows bắt buộc phải qua xác nhận Human-in-the-Loop.
  - Khi hoàn thành tác vụ nặng (Kanban), tự động gửi thông báo kèm file kết quả về đúng kênh yêu cầu.
